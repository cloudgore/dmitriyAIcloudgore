Джарвис — Яндекс Музыка, версия 1.1

Расширение нажимает кнопки только на https://music.yandex.ru/.
Команды: включить, продолжить, пауза, следующий и предыдущий трек.
Пауза и продолжение задают нужное состояние. Неоднозначные кнопки не нажимаются.

Расширение связывается с помощником по http://127.0.0.1:17843.
Сервер слушает только локальный компьютер. Передаются только фиксированные
названия музыкальных действий и подтверждения, без текста речи и вопросов.
Сервер не принимает команды управления от сайтов. Доступ к другим сайтам,
файлам и микрофону расширению не нужен.

Первое включение музыки также работает по специальной ссылке:
https://music.yandex.ru/?jarvis_play=1

После обновления файлов перезагрузите расширение, затем вкладку музыки.
Если browser://extensions/ перенаправляет на browser://tune/ без кнопки
обновления, полностью выйдите из Яндекс Браузера через меню «Выход»
и откройте снова. Проверьте, что расширение включено.
Выключение/включение в browser://tune/ может не обновить манифест.

Идентификатор расширения согласован с music_extension_id в config.json.
Произвольные команды и код через музыкальный канал не выполняются.
