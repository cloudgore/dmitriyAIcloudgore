ДЖАРВИС — локальный голосовой помощник Windows

ОПТИМИЗАЦИЯ СКОРОСТИ QWEN
Выбран измеренный более быстрый CPU-режим: 6 потоков, контекст 1024,
короткий ответ одним предложением. При запуске прогреваются и модель,
и её служебный запрос. До 16 повторных вопросов-определений с ответами
кэшируются только в оперативной памяти до выхода из приложения.
В контрольной проверке подготовленная модель ответила об ОЗУ за 4.13 с,
повторный ответ не потребовал нового расчёта. Озвучивание занимает отдельное время.

СИГНАЛ, МУЗЫКА И ВОПРОСЫ — ОБНОВЛЕНИЕ
Сигнал активации — отчётливый короткий WAV через обычный аудиовыход,
а не системный Beep. Он звучит и для цельной фразы «Димон, включи музыку».
Для коротких имён Дима/Димон/Дмитрий учитывается менее строгая оценка имени
(name_confidence=0.5), но команда по-прежнему проверяется отдельно и только
по белому списку. Слова «пожалуйста», «мне», «ты», «можешь» можно комбинировать.
Раннее принудительное обрезание фраз отключено (fast_endpoint=false):
Vosk должен дослушать вопрос/команду целиком. Вопросы про «ОЗУ», включая
распознанное «о з у», разворачиваются в вопрос об оперативной памяти.
После принятого вопроса звучит «Думаю», после поиска — «Ищу в интернете»;
расчёт уже идёт параллельно этой короткой реплике.
Для автозапуска музыки расширение «Джарвис — Яндекс Музыка» должно быть
включено в Яндекс Браузере. Если оно выключено, сайт откроется без нажатия играть.

ДОПОЛНЕНИЕ: автоматическое усиление тихой речи включено (automatic_gain).
В списке микрофонов показываются WASAPI, а при их отсутствии MME;
неработающие WDM-KS и дубли DirectSound скрыты. Ошибка проверки микрофона
в фоновом потоке Windows устранена и проверена на реальном захвате.
Команда времени теперь озвучивается сохранёнными словами Dmitry Neural
локально, без сети и без Ирины: «Сейчас одиннадцать двадцать пять».
Словарь всех часов и минут подготовлен; не удаляйте voice-cache для офлайн-работы.
Произвольные новые ответы Qwen ещё зависят от онлайн-озвучки Microsoft,
и при её сбое по-прежнему используется ранее согласованный резерв SAPI.

БЫСТРЫЙ ОТКЛИК И ИМЕНА
Обращения: «Дима», «Димон», «Дмитрий» и прежнее «Джарвис».
После отдельного имени звучит короткий сигнал вместо длинного «Слушаю».
Сразу после сигнала произнесите команду. Можно одной фразой:
«Дима, включи музыку», «Дмитрий, который час».
В примерах ниже «Слушаю» теперь означает этот короткий сигнал.
Чтобы вернуть голосовое подтверждение: wake_ack="voice" в config.json
и перезапуск. По умолчанию wake_ack="tone".
Умеренное усиление звука выполняется внутри Джарвиса (microphone_gain=1.6),
настройки громкости и приватности Windows не меняются.
Системный микрофон по умолчанию открывается через WASAPI, если доступен
тот же физический микрофон; явно выбранное устройство сохраняется.
По умолчанию используется штатное завершение фраз Vosk без раннего обрезания.
Учтены фиксированные варианты записи Vosk: «демон» для «Димон» и «димо»
для «Дима», только в начале обращения. Это может увеличить ложные активации
на похожие имена; произвольные системные действия всё равно недоступны.
Qwen заранее загружается при запуске в фоне. Для экономии времени ответа
уменьшена длина ответа; «Думаю» озвучивается параллельно расчёту.

НОВАЯ СХЕМА
Модель: Qwen3 1.7B Q4_K_M через переносную Ollama в ollama-runtime.
Распознавание: Vosk. Озвучка: Edge TTS ru-RU-DmitryNeural.
Поиск: DuckDuckGo. Активация: «Джарвис». Действия: Python и белый список.
Ollama запускается по необходимости только на 127.0.0.1:11435.
Модель хранится в ollama-models, настройки Ollama — в ollama-profile.
Программа не добавляется в PATH, службы и автозапуск Windows.

ВОПРОСЫ И ПОИСК
«Джарвис» → «Слушаю» → «Объясни, что такое оперативная память».
На вопросы отвечает локальная Qwen3. Две последних пары сообщений
хранятся только в памяти до выхода из Джарвиса.
«Джарвис» → «Слушаю» → «Найди в интернете информацию о Питоне».
Поиск запускается только словами «найди…» или «поищи…»; запрос отправляется
DuckDuckGo. Результаты и ссылки показываются в отдельном окне, краткий
ответ озвучивается. Страницы и результаты поиска не могут запускать команды.
Если обычный поиск требует CAPTCHA/недоступен, используется официальный
Instant Answer API DuckDuckGo. Он покрывает только часть запросов. Если
данных нет, окно содержит ссылку на обычный поиск, а не выдуманный ответ.
При включённой Qwen распознавание не ограничено только словарём команд.

Модель не получает доступ к командной строке, файлам, микрофону и приложениям.
Её ответы никогда не исполняются как Python/PowerShell. Действия выполняются
только по белому списку. Ollama работает локально, облачные модели отключены.
Текст голосовых ответов, включая ответы Qwen, озвучивается сервисом Microsoft.
Нейросетевые ответы не сохраняются в голосовом кэше: временный MP3 удаляется
после воспроизведения. Текст окна ответа не записывается в файл.
На этом компьютере ограничены контекст (1024), потоки CPU (6), число
одновременно загруженных моделей (1). Через 10 минут простоя модель
выгружается из оперативной памяти. Первый ответ может занять больше времени.

ЗАПУСК
Дважды нажмите Jarvis.lnk (ярлык). Запасной способ: Start.vbs.
Окна консоли нет, возле часов появляется бирюзовый
значок (возможно, внутри скрытых значков). Правой кнопкой: пауза микрофона
или выход. Пауза не закрывает устройство, но отбрасывает входящий звук.
Для полного освобождения микрофона выберите «Выход».
Для диагностики: Start-console.cmd; журнал ошибок — jarvis.log.
Повторный запуск не создаёт второго слушателя в той же сессии Windows.

КАК ГОВОРИТЬ
«Джарвис, открой калькулятор» — одной фразой с последующей паузой.
Или: «Джарвис» → ответ «Слушаю» → команда в течение 12 секунд.
После выполненной команды или ответа на вопрос обращение нужно повторить.
Паузы и слишком неуверенная речь не вызывают отказов вслух: до конца этих
12 секунд можно повторить команду. По истечении окна снова назовите Джарвиса.
Можно менять порядок слов и использовать вежливые формулировки:
«музыку включи», «включи мне музыку», «пожалуйста запусти музыку»,
«можешь включить музыку», «калькулятор открой», «прибавь громкость».
Управление приложениями использует набор разрешённых вариантов; остальные
осмысленные вопросы передаются Qwen3 для текстового и голосового ответа.
В запасе есть русская фраза «слушай помощник» с теми же командами.
Если имя распознаётся плохо, используйте запасную фразу.
Точность зависит от микрофона, шума и произношения. Слово активации не
проверяет личность: чужой голос или звук из колонок тоже может сработать.

КОМАНДЫ (перед каждой — «Джарвис»)
включи музыку / открой яндекс музыку — открывает сайт и запускает музыку
запусти музыку / включи яндекс музыку — то же действие
плей пауза — переключает воспроизведение в активном медиаплеере Windows
следующий трек / предыдущий трек — медиаклавиши активного плеера
громче / тише — по 3 нажатия клавиши громкости
выключи звук / включи звук — явное отключение/включение звука
открой блокнот / открой калькулятор / открой браузер
который час / что ты умеешь / отмена / выключи помощника

ЯНДЕКС МУЗЫКА
Нужны интернет и ваш вход в аккаунт; доступность воспроизведения зависит
от условий сервиса. Установлено локальное расширение из browser-extension;
music_autoplay включён. Специальная ссылка от Джарвиса запускает расширение,
которое находит и нажимает «Играть» один раз. Если музыка уже играет,
она не ставится на паузу. Папку расширения не перемещайте.
Если расширение выключено или кнопки сайта изменились, нажмите играть вручную.
Для отключения: music_autoplay=false в config.json и перезапуск Джарвиса.
Браузер также может ограничивать автоматическое воспроизведение.
«Плей пауза» работает с выбранным Windows медиаплеером, которым может
оказаться другое приложение. Джарвис не обходит вход и ограничения сайта.
Голос и распознавание работают локально; сайт музыки является онлайн-сервисом.

МИКРОФОН
Выбор: правой кнопкой по значку Джарвиса возле часов → «Выбрать микрофон…».
Выберите устройство и нажмите «Применить». Настройка сохраняется и
применяется без перезапуска. «По умолчанию в Windows» возвращает системный
выбор. «Обновить список» обновляет устройства после подключения гарнитуры.
Окно также можно открыть ярлыком Microphone.lnk в папке помощника.
Перед сохранением проверяется доступ к микрофону. Системные настройки
Windows не изменяются. При недоступности выбранного устройства Джарвис
остаётся запущенным: можно выбрать другое через его значок.
Список устройств для дополнительной диагностики:
.venv\Scripts\python.exe jarvis.py --devices
Выбор сохраняется по имени и аудиосистеме устройства, а не только по номеру.
Если Windows запрещает микрофон: Параметры → Конфиденциальность и
безопасность → Микрофон → доступ для классических приложений.
Настройки доступа помощник сам не меняет.

БЕЗОПАСНОСТЬ И ДАННЫЕ
Нет облачного распознавания, записи микрофона и сохранения разговоров.
Голос переключён на Microsoft ru-RU-DmitryNeural через edge-tts.
Только текст ответов Джарвиса отправляется сервису Microsoft; речь с
микрофона туда не отправляется. Интернет нужен для новых реплик.
Готовые реплики сохраняются в voice-cache (до 128 MP3) и повторяются локально.
При недоступности сервиса для новой реплики используется голос Windows.
Для полностью локального голоса задайте speech_provider="sapi" в config.json.
Для выбора голоса/режима перезапустите помощника. Документация компонента:
https://github.com/rany2/edge-tts
В журнале только названия выполненных команд, запуск и ошибки.
Никакая распознанная строка не выполняется как код, путь или команда ОС.
Список приложений и адресов фиксирован в исходниках. Системные настройки,
реестр и автозапуск голосом не изменяются. Речь Windows не попадает в
распознаватель; микрофонные блоки во время ответа отбрасываются.
Для обращения требуется уверенность Vosk >= 0.65, для команды — средняя
уверенность >= 0.60 и точное совпадение с разрешённой формулировкой.
После обращения используется словарь разрешённых фраз с категорией
неизвестной речи; после выполнения снова включается обычное распознавание.

АВТОЗАПУСК (ПО ЖЕЛАНИЮ, ПО УМОЛЧАНИЮ ВЫКЛЮЧЕН)
Autostart-enable.cmd — включает после подтверждения Y.
Autostart-disable.cmd — выключает. Администратор не нужен.
Используется только значение JarvisOffline в HKCU\Software\Microsoft\
Windows\CurrentVersion\Run. Включайте после проверки голоса и микрофона.
Перед перемещением/удалением папки обязательно выключите автозапуск.
Удаление: выйдите через значок, выключите автозапуск, удалите папку Jarvis.
Глобальные библиотеки Python и службы Windows не устанавливаются.

КОМПОНЕНТЫ
Vosk 0.3.45 + vosk-model-small-ru-0.22 (Apache 2.0, модель ~45 МБ),
sounddevice/PortAudio, pystray, Pillow, edge-tts; Dmitry Neural с резервной
Ириной из Windows SAPI.
Источники: https://alphacephei.com/vosk/models
https://github.com/dscripka/openWakeWord#language-support
openWakeWord официально ориентирован на английский. Здесь активация
реализована через полноценное русское распознавание Vosk, а не через
специальную обученную модель wake word. Требуется практическая проверка.
